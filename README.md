# Azure Cost Calculator: About

This application allows a user to calculate the yearly cost of hosting 
a cloud service on Microsoft Azure.

## Features
- Select from 7 instance sizes (Very Small to A7)
- Input number of instances (minimum 2 as per Azure SLA)
- Calculates yearly cost accounting for leap years
- Validation on all inputs
- Confirmation page displaying full cost summary

## Technologies Used
- ASP.NET Core MVC
- C#
- Razor Views
- Entity Framework (model validation)
- HTML/CSS
